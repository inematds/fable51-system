# Fable 5.1 na prática — o que mudou, como usar, como gastar menos

Curso INEMA.CLUB (formato v2, 3 trilhas, 9 módulos, 54 tópicos) sobre o prompt de sistema do Claude Fable 5.1: entender a mudança sem hype, rodar os cinco testes na própria conta, gastar menos.

**Página:** https://inematds.github.io/fable51-system/

## Projeto de referência (material-fonte, análise, fichas)

O material que embasa o curso vive num repositório separado, para ser usado sem o curso:
**[`inematds/fable51-system-prompt`](https://github.com/inematds/fable51-system-prompt)** — análise dos três números e das 28 ferramentas, índice do dump (40 seções), fichas dos 5 testes, "escrever para o Fable" e custo/esforço.

## Estrutura

- `index.html` — landing + 3 trilhas
- `curso/trilha1..3/` — módulos
- `build/` — gerador (`node build/build.mjs`)
- `doc/` — material-fonte local (não publicado; cópia também em `fable51-system-prompt/doc/`)
- `PROPOSTA-CURSO.md` — proposta e análise original · `FALHAS.md` — changelog de falhas
